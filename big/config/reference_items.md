# 标准可参考商品说明（按用户 / reference_key）

## gpu_quadro

用户目标：采购 **NVIDIA 专业显卡 / 工作站卡**（Quadro / RTX A 系列 / RTX 4000/5000/6000 专业卡），用于工作站或渲染，不是游戏卡收藏。

### 明确接受
- Quadro P2000 / P2200 / P4000 / P5000 / P6000
- RTX A2000 / A4000 / A5000（及同系 A6000 若标题明确）
- RTX 4000 / RTX 5000 / RTX 6000（**专业工作站卡**，含 Ada 版如 RTX 4000 Ada 等，标题需能判断是专业卡）
- 单卡主板卡、盒装/散装均可；日文标题含「グラボ」「グラフィックボード」「Quadro」「RTX A」等且型号匹配

### 明确拒绝（标题党 / 不符）
- **错型号**：搜 P4000 时出现的 P400 / P600 / P620 / P1000 / P2000（标题没有目标型号）
- 消费级游戏卡：RTX 4060/4070/4080/4090、RTX 3060/3070/3080/3090、GTX 系列等（仅因含 “4000/5000/6000” 数字撞车）
- 仅线材、转接器、**3Dステレオブラケット**、螺丝、说明书、空盒、保修卡
- **整机/工作站**：含 Xeon / メモリ / SSD / HDD / Win10/11 / ThinkStation / Precision / HP Z 系列机箱等，即使写了目标显卡型号也拒绝（用户要的是单卡）
- 笔记本、小主机
- 明显山寨/不知名杂牌且无法看出是 NVIDIA 原厂专业卡
- 只写 “P2000” 但上下文是别的产品（打印机、相机、工具等）
- 挖矿板严重变形、仅残件核心、明显报废无法作为工作卡使用（若标题已写坏品/ジャンク且无法使用）
- 已售/取引中（非在售）

### 判断原则
- 关键词命中不够，必须从标题判断 **型号与系列** 是否属于上表专业卡
- **型号边界**：P400 ≠ P4000，P600 ≠ P6000
- 有疑义偏向拒绝，并在 reason 说明

## keyence_melsec

用户目标两类工业品，需分开判断：

### A. Keyence（基恩士）
- 接受：Keyence / キーエンス 传感器、视觉、激光、PLC 周边、读码器、放大器、电缆（原厂或明确兼容且写清型号）
- 拒绝：仅广告册、空箱、无关 “key” 英文词撞车、明显非 Keyence 品牌却蹭词

### B. 三菱电机 CPU / 三菱 PLC CPU
- 接受：三菱電機 / Mitsubishi / MELSEC 的 **PLC CPU 单元**（如 Q 系列、L 系列、iQ-R、FX 等 CPU 模块，标题含 CPU / シーケンサ CPU 等）
- 拒绝：
  - 普通 PC 的 CPU（Intel/AMD 酷睿、Ryzen 等）——即使同时出现「CPU」「三菱」字样也要小心
  - 仅继电器、端子台、空壳、说明书、与 CPU 单元无关的三菱家电
  - 标题党：写了三菱/CPU 但主体是别的模块且无法确认为 CPU 单元

### 判断原则
- “Keyence” 与 “三菱 CPU” 是两类；商品只需符合其中一类即可通过
- 必须能从标题看出品牌+品类；仅关键词碰巧匹配则拒绝

## arcteryx_apparel

用户目标：采购 **始祖鸟 Arc'teryx（アークテリクス）的衣服**。只要成衣，不要包袋、鞋帽和其他配件。

### 明确接受
- 始祖鸟 / Arc'teryx / ARC'TERYX / アークテリクス 的成衣：外套、冲锋衣、硬壳、软壳、抓绒、羽绒、马甲、裤子、衬衫、T恤、卫衣、打底、内衣
- 男女款、儿童款均可；新旧、有使用痕迹均可，只要标题能判断主体是该品牌衣服
- 常见服装系列（Alpha、Beta、Atom、Gamma、Cerium、Thorium、Proton、Kyanite、Squamish、Zeta、Norvan 等）且主体是衣服

### 明确拒绝（标题党 / 不符）
- 背包、腰包、手提包、托特、钱包（バックパック、リュック、バッグ、ウエストバッグ、ポーチ 等）
- 帽子、头带、手套、袜子、鞋子、腰带、贴纸、钥匙扣、挂件
- 空盒、吊牌、说明书、目录、仅替换拉链 / 魔术贴 / logo 补丁
- 非始祖鸟品牌，或标题只是蹭「アークテリクス」但主体是别的牌子
- 标题已写明仿品、高仿、レプリカ、偽物、コピー、非正規
- 无法判断是衣服的周边、海报、杂志
- 已售 / 取引中（非在售）

### 判断原则
- 必须同时满足：品牌是始祖鸟，且商品主体是衣服
- 包、帽、手套、鞋一律拒绝，即使是正品始祖鸟
- 有疑义偏向拒绝，并在 reason 说明
